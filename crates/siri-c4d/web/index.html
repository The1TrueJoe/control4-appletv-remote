Voice

Holding Siri records 16 kHz mono audio and writes a WAV here. Speech recognition is intentionally not part of this project — point your own at these files, or use siri-events --pcm-fifo for a live PCM stream while the button is held. Requires a Bluetooth 4.2+ adapter; the remote refuses a large enough MTU otherwise.
